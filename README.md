<details>
<summary><b>Technical Highlights</b></summary>

#### Game Data Architecture

`UserManager`와 `BackendManager`를 분리하여
런타임 게임 데이터 관리와 서버 데이터 저장 책임을 구분했습니다.

주요 데이터 모델은 다음과 같습니다.

| 데이터 모델 | 관리 정보 |
| :--- | :--- |
| PuserInfo | 플레이어 재화, 인벤토리, 진행도 |
| PDungeonInfo | 던전 능력치 |
| PEquipInfo | 장비, 스킨, 직원 정보 |

#### Backend Data Persistence

- `IsDifferent()`를 통한 데이터 변경 감지
- `Param` 객체 기반 서버 저장 데이터 구성
- `TransactionWriteV2` 기반 비동기 저장
- `DeepClone` 기반 데이터 스냅샷 관리
- 최초 데이터 생성 및 기존 데이터 불러오기

각 게임 기능에서 `SaveData()`를 호출하고,
공통 저장 시스템에서 변경된 데이터를 선별하는 구조입니다.

#### Inventory & Production

- 물고기 및 재료의 보유 수량 관리
- 아이템 유형별 수량 또는 보유 상태 관리
- 생산 스탠드 및 레시피 데이터 관리
- 창고 선택 시 캐릭터 주변 인벤토리 UI 표시

</details>
